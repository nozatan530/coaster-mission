# バランス試算の結果

`npm run balance`（`scripts/balance.ts`）で、concept.md「試算で確かめたバランス」の代表5設計を、ばらつきありで1設計 1,000 回ずつ走らせる。乱数の種は固定しているので、同じ回数なら毎回同じ結果になる。発射の角度は、どれも缶の中心へまっすぐ向ける。

## いまのルール（2026-10-20 から）

- 缶は高くつるすほど遠くに置く：60 cm → 0.80 m、80 cm → 0.95 m、100 cm → 1.10 m、120 cm → 1.25 m、140 cm → 1.40 m（`src/physics.ts` の `CAN_DISTANCES`）
- 左右のずれは、缶までの距離 1 m あたり標準偏差 2.0 cm（`VARIABILITY.lateralStdPerM`）

### ここから言えること

- 最上段（140 cm）と1段下（120 cm）の差は、平均で 1.3〜4.6 点。10回連続の平均点は運だけで±9点ほど揺れる（命中と外れで約80点違い、成功率80%前後のとき）ので、**最上段を選べば必ず勝てる状態ではなくなった**
- 遠い缶ほど左右に外れやすく、140 cm の成功率は 120 cm より 5〜14 ポイント低い。「高い缶は点が高いが外れやすい」が数字に出る
- 缶の大きさは、中の缶がいちばん得なことが多い。小さい缶は低い（近い）缶で強い
- 缶が発射台より低いと、角度を下向きにできないので当たらない（ループなしの 60 cm が 0%）

## 決めるまでの経緯（2026-10-20）

最初のルール（どの缶も 1.0 m 先、左右のずれは距離によらず 3 cm）では、4設計すべてで「中の缶を 140 cm」がいちばん得で、140 cm と 120 cm の差は 6〜9 点だった（最上段一択）。次の候補を、缶ごとに発射台の高さも選び直す条件で比べた。

| ルール | 140 cm と 120 cm の差 | 各設計のいちばん良い平均点 |
|---|---|---|
| 最初のルール（1.0 m 先・左右 3 cm） | 6.3〜8.9 点 | 86〜102 点 |
| 高い缶ほど遠く（左右は 3 cm のまま） | 3.3〜6.6 点 | 82〜97 点 |
| 高い缶ほど遠く＋左右を距離比例（1 m あたり 3.0 cm） | −0.2〜4.1 点 | 75〜89 点 |
| 〃（1 m あたり 2.5 cm） | 1.1〜4.2 点 | 79〜93 点 |
| 〃（1 m あたり 2.25 cm） | 1.3〜4.9 点 | 81〜96 点 |
| **〃（1 m あたり 2.0 cm）← 採用** | **0.7〜3.8 点** | **83〜98 点** |

- 遠くするだけでは、左右のずれが距離によらず一定なので効きが弱かった
- 左右のずれを距離に比例させると最上段の得は縮むが、ずれを大きくするほど全体の平均点が下がる。最上段の得が小さく、平均点の下がりが少ない 2.0 cm を採った
- 2.0 cm では、缶の大きさの選び分け（遠い缶は大きい缶で確実に）はほとんど出ない。缶の大きさでも迷わせたいなら 2.5 cm 寄りにする手がある
