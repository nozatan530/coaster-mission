- [x] 依存の衝突を直し、`npm install`・型チェック・ビルドが通る状態にする（esbuild を ^0.28）
- [x] 確認用3設計を自動で確かめるスクリプト `scripts/check-physics.ts` を作る（テストの代わり。`npm run check:physics`）

- [x] バランス試算スクリプト：代表5設計を1,000回ずつ走らせ、平均点・成功率を concept.md の表と比べる。缶の高さが最上段一択になっていないかも数値で見る（`npm run balance`、結果は `docs/balance.md`。最上段一択を確認 → 高い缶ほど遠く＋左右のずれを距離比例（1 m あたり 2.0 cm）に調整済み）
