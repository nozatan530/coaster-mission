## 実装タスク
通常ルート（AIなし）。AI Studio の試作をもとに、仕様（`docs/concept.md`・`docs/studio-prompt.md`）と照合しながら仕上げる。1つ30分〜1時間。

- [x] 依存の衝突を直し、`npm install`・型チェック・ビルドが通る状態にする（esbuild を ^0.28）
- [ ] 確認用3設計を自動で確かめるスクリプト `scripts/check-physics.ts` を作る（テストの代わり）
- [ ] B設計の1点差（107点、仕様は108点）の原因を特定し、計算の順番を仕様に合わせる（またはどちらに合わせるか決める）
- [ ] バランス試算スクリプト：代表5設計を1,000回ずつ走らせ、平均点・成功率を concept.md の表と比べる。缶の高さが最上段一択になっていないかも数値で見る
- [ ] 幅360pxで全画面を確認し、崩れを直す（コース図の縦の見え方を含む）
- [ ] 練習ステージ3つの問い・ヒント3段階・照準線（答えたあとで表示）を仕様と照合して直す
- [ ] 試走：失敗理由の候補と10回連続の表示（平均点・成功率・内訳・理想の点）を照合して直す
- [ ] 記録表と「何を変えたか・なぜか」の入力欄を照合して直す
- [ ] レポート：A4縦1〜2枚の印刷レイアウト、足りない項目の印、テキストのコピー
- [ ] localStorage が使えないときの動作と、リセットの確認ダイアログ
- [ ] 公開準備：パッケージ名・タイトル・ビルドの base 設定（`coaster-mission.meetupsensei.com` 向け）
