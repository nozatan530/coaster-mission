# 過去の開発から教訓を掘り起こす

1. 材料を読む（あるものだけ）：`git log --reverse --stat`（全履歴）、`README.md`、`CLAUDE.md`、`docs/` の全ファイル、`/Users/nozkoh/code/claude-work` 内でこのアプリ名を含む md（制作記・worklog）。
2. 開発の流れを時系列で5〜8行に要約し、次の3つを抜き出す。
   - 手戻り・作り直しが起きたところ（何を、なぜ）
   - 最初に決めていれば楽だったこと
   - うまくいった工夫
3. ユーザーに2〜3問だけ聞く：実際に使った場面と生徒の反応／今いちばん直したいところ／作っていて楽しかった・しんどかったところ。
4. 結果を仕分けて書く。
   - `docs/retro.md` の先頭に「## yyyy-mm-dd これまでの振り返り（harvest）」として記録
   - このアプリで次にやること → `docs/spec.md` の実装タスク（spec.md がなければ作る）
   - 次のアプリにも効く教訓 → `/Users/nozkoh/code/ideas/LESSONS.md` の該当見出しへ（日付・アプリ名付き、重複は ×2）
5. コミットして、3行で報告：見つけた教訓の数／追加したタスク数／note の制作記に使えそうな話題。
以降の振り返りは `/retro` を使う。
